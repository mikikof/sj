自己紹介カードをつくる｜品川女子学院
中学1年生向け / CodePen × Gemini

使い方
1. ZIPを展開し、フォルダ内の index.html を開いてください。
2. 上部の1〜3（準備する・コードを貼る・AIに頼む）から、授業の場面を選べます。
3. 生徒はCodePenで編集し、必要に応じてGeminiに変更を頼みます。
4. 先生用の補足・授業前の準備は「進行メモ」にあります。

配布
index.html、app.css、starter.js、app.jsを同じフォルダに置いてください。
静的Webサイトとして学校の配布環境に置くこともできます。
教材の見本表示は外部画像・ライブラリ・Webフォントに依存しません。
CodePenとGeminiの利用にはインターネット接続が必要です。
サイトを公開した場合も、生徒が入力した控えがサイトへ送信されることはありません。

保存されるもの
この教材に貼ったHTML/CSS、指示文、チェックを同じブラウザ内に保存します。
CodePenで編集した内容は、自動でこの教材には取り込まれません。
AIに頼む前に、CodePenのいまのコードをこの教材へコピーしてください。
端末・ブラウザ・教材を置いた場所が変わると、控えが引き継がれないことがあります。
「控えてあるコードを見る」からコードをテキストファイルで保存できます。
ブラウザの保存やクリップボードが制限された場合は手動コピーを案内します。

先生へ
生徒用端末・学校アカウントでCodePenとGeminiが開けるか事前に確認してください。
冒頭にCodePenのアカウント作成ボタンがあります。先生の説明に沿って登録してください。
利用できない生徒は先生の実演で進められます。
CodePenはHTML/CSS/JSの3欄があるClassic Editorを案内しています。
本名や顔写真の登録は不要です。作品の保存・公開範囲・提出先は学校の運用に合わせてください。
見本の氏名・内容は編集用です。生徒が自由に書き換えることを前提としています。

確認範囲
コード構文、画面遷移、コピー対象、指示文生成、最新コードへの入替確認、
再読込、保存・コピーができない場合の案内を確認しました。
Chrome と WebKit（Safari のエンジン）で、段の移動・HTMLとCSSのコピー・指示文の生成とコピー・「いまのコードを使う」の切り替え・控えの窓・再読込を確かめました（2026年10月23日）。
学校端末・学校アカウントでの接続は未確認です。
