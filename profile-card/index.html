03 / AIに頼む

変えたい場所を、言葉で伝える。

ミッション：Geminiに頼んで、見た目を2か所以上変える。1回に、1つの変更から。

ここに書くと、右にGeminiへ送る指示文ができあがります。カードのコードも自動で入ります。

例から考える クリックで入力

例を選んだら、色や場所を自分の好みに書き換えてみよう。

「おしゃれに」から、もう一歩。

「背景は白、見出しは紺。余白を広くして、すっきり見せて」のように、どこを・どうを入れて伝えると、確かめやすい。

2Geminiに送る指示文見本のコードを使用
Geminiへ ↗
  1. Geminiの入力欄に貼り付けて、送信する。
  2. 返ってきたCSSを、CodePenのCSS欄に丸ごと置き換える。HTML欄はさわらない（書き換えた名前や文章がそのまま残る）。
  3. 返ってきたHTMLとCSSを、CodePenのそれぞれの欄に丸ごと置き換える。
  4. 2回目からは、同じGeminiの会話に頼みたいことだけを書いて送ればOK。
必要なときだけ：項目を足す・CodePenのいまのコードを使う

ふだんは見本のコードで指示文を作り、GeminiにはCSSだけを返してもらいます。項目を足すなどHTMLも変えたいとき、新しいGeminiの会話で続きを頼むとき、返事がうまくいかないときは、CodePenのいまのHTMLとCSSを両方ここに貼ってください。指示文がそのコードを使い、HTMLとCSSの両方を返してもらう形に変わります。

04 / 提出する

できたカードを送る。

送ったカードは、先生が確かめてから、みんなで見られるページにのせます。

  1. 1
    CodePenの右上の「Save」を押す。アカウントに入っていないと保存できません。右上に「Log In」が出ていたら、先にログインします。
  2. 2
    アドレス欄のURLをコピーする。保存すると、URLが codepen.io/ユーザー名/pen/英数字 の形に変わります。アドレス欄をクリック → ⌘＋C。
  3. 3
    下の欄に貼り、クラスと名前を入れて送る。

2クラス

本名を書きます。先生が確かめるためのもので、一覧には出しません。

送った記録

このブラウザにだけ残ります。

    まだ送っていません。

    01 / 04上の番号から、どこへでも移動できます。

    困ったとき

    CodePen・Geminiが開けない

    学校で使うアカウントか確認して、先生に知らせましょう。CodePenの登録は冒頭のボタンから、先生の説明に沿って進めます。Geminiが使えないときは、先生の画面を見て変更を試します。

    コピーできない

    コード欄や指示文の中をクリックし、Macは⌘＋A → ⌘＋C、WindowsはCtrl＋A → Ctrl＋C。コピー先では⌘／Ctrl＋Vで貼り付けます。

    カードのデザインが表示されない

    HTMLだけでなく、CSSも「CSS」欄に貼ったか確認します。HTMLとCSSを逆に貼っていないかも見てみましょう。

    最初の見本からやり直したい

    「02 コードを貼る」から見本のHTMLとCSSをもう一度コピーできます。CodePenのいまの内容は置き換わるので、残したいものは先に保存してください。

    提出できない

    URLが codepen.io/pen/ のままなら、まだ保存されていません。右上の「Save」を押します。Saveが押せないときは、ログインしているかを確かめます。

    貼ったコードを取り出したい

    「03 AIに頼む」の「必要なときだけ」の欄に最後に貼ったコードを取り出せます。CodePenでその後に変更した内容は、ここには自動では戻りません。

    貼ったコードの控え

    CodePen側のコードは自動で変更されません。必要な欄に自分で貼り戻します。
