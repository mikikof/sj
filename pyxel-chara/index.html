保存して、Code Maker で開く

  1. Pyxel Code Maker を開きます。
  2. 上の Load → File で、保存した ZIP をえらびます。
  3. 右の画面をクリックして、←→・SPACE・Z で動かしてみます。
  4. 直したくなったら、このページで直して保存し直すか、Code Maker の Res で直して Run を押します。
  5. 終わる前に Save → File で ZIP を保存します。次の時間はその ZIP から始めます。

Code Maker の Res で黒（パレットのいちばん左上）で塗った所は、ゲームでは透明になります。キャラの黒い所は、そのとなりの紺で塗ります。

画像はこのページの中だけで使い、どこにも送りません。

困ったとき

背景が残る／キャラまで消える
2 の「消す強さ」を動かします。手描きの写真で背景が残るときは、絵の上をドラッグして、使う範囲を絵のまわりだけにします。
白いキャラの背景が消えない／キャラまで消える
1 の「キャラをえらぶ」を押してから、キャラの中をクリックします。クリックしたキャラだけが残り、ほかは消えます。広がりすぎるときは、2 の「消す強さ」を弱くしてから、「クリックを 1 つもどす」でやり直します。
目が出ない・目がつぶれる
2 の「目などの小さな黒い点を残す」を入れます。16×16 では目は 1 マスの点になります。思った所に出ないときは、3 で 1 マス塗ります。
自動でうまくいかない
3 の「元の絵を重ねる」を入れると、元の絵がうすく重なります。それを見ながら、ぬる・けす・バケツで描き直します。「このコマをまっさらにする」を押してから、なぞって描くこともできます。
色が元の絵と違う
Pyxel で使える色は 16 色だけなので、いちばん近い色に置き換わります。うすい色が白になるときは、2 の「色のこさ」を上げます。Code Maker の Res でも塗り直せます。
キャラが小さい・大きい
2 の「キャラの高さ」で変えます。16 マスがいちばん大きい形です。位置は 3 の矢印で 1 マスずつずらせます。
カメラが映らない
ブラウザが「カメラを使いますか」と聞いてきたら、許可します。ほかのアプリがカメラを使っているときは、そちらを閉じます。
iPhone の写真が開けない
HEIC という形の写真は開けないことがあります。「カメラで撮る」を使うか、画面のスクリーンショットを使います。
ZIP を開けない
ZIP をダブルクリックで展開せず、Code Maker の Load → File で、ZIP のままえらびます。
