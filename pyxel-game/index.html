HELP
困ったとき

      

        
キーが効かない
Code Maker の右のゲーム画面を押してから、矢印キーや Z を押します。左のコードの欄にカーソルがあると、ゲームにキーが届きません。

        
Failed to open file 'umplus_j10r.bdf' と出た／画面に Open your character ZIP first と出た
字のファイルが入っていません。コードは直さず、Gemini にも頼みません。先にキャラの ZIP を Load → File で開き、コードの欄を全部消してから、もう一度貼ります。

        
日本語が出ない
キャラを使う場合は、キャラの ZIP を Load → File で読み込みます。umplus_j10r.bdf を読み込み、pyxel.text にフォントを渡すコードが必要です。キャラを使わない場合は、画面の文字を英語にします。02 の「1 つだけ足してもらう」に直したいことを書けます。

        
キャラが出ない・消えた
01 の「自分のキャラを使う」が入っているか、キャラの ZIP を読み込んだかを確かめます。pyxel.load("my_resource.pyxres") が必要です。画像 0 の 1 段目を書き換えるコードがあると、キャラの絵が消えます。絵が変わった場合は元の ZIP を読み込み直し、直したコードを貼ります。色 0 は透明です。

        
エラーが出た
Failed to open file 'umplus_j10r.bdf' の場合は、上の同じエラーの項目にある手順で貼り直します。それ以外のエラーは、最後の行を含めた数行をコピーします。02 の「エラーを直してもらう」に貼り、できた文を同じ Gemini の会話に送ります。返ってきたコードの全文で、Code Maker のコードを置き換えます。

        
保存するには（自動保存はありません）
Code Maker の Save → File で ZIP を保存します。次は Load → File で、その ZIP を選びます。キャラの絵とコードをまとめて残せます。このページに書いたアイデアも自動保存されないので、必要なら頼む文をコピーして手元に残します。
