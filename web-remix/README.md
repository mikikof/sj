# HTML・CSS キャラページ編集教材 生徒版 1.1

中学1年生向けのHTML/CSS教材。5体からキャラを選び、紹介ページを編集して表示を確かめます。特技のボタンを押すと、そのページでキャラが動きます。「もっと見る」では好きなものを紹介する別ページへ移ります。

HTMLの内容とCSSの見た目を中心に扱う生徒版です。JavaScriptは動きを支えるコードとして読むことができます。ゲームの操作画面は含みません。従来のゲーム付き教材は別の教材として残しています。

## 起動と配布

`web-remix-student.zip` を展開して `index.html` をブラウザで開きます。Webで配信する場合は `dist` の中身を配置します。外部ライブラリ、APIキー、ビルドは不要です。確認用サイトは所有者限定です。

`downloads/student-sheet.pdf` は生徒用3ページ、`downloads/teacher-guide.pdf` は先生用4ページです。50分の進行例も入っています。ZIPにZIP自身は含めません。

## 授業中の進め方

最初にミント・ヒバナ・シロ・ノヴァ・アクアの5体からキャラを選びます。そのキャラの固有技6個から1〜3個を選び、「このキャラで始める」を押します。保存した作品がある場合は「続きから」で再開できます。「最初から」はキャラ選択画面を開く操作で、この時点では作品を消しません。新しく選んで始めるときに作品を切り替えます。この切り替えも「1つ前に戻す」で取り消せます。

編集画面は最初にページだけを表示します。表示結果の上にある「コードを見る」で編集欄を開き、同じ位置の「コードを隠す」で閉じます。もう一度開くと直前の表示に戻ります。開いている間は「表示するコード」でHTML・CSS・HTML＋CSS・JavaScriptを選べます。HTMLとCSSは編集でき、JavaScriptは実際の動作コードを読むための表示です。

上の1〜5の場面は先生の声かけに合わせて切り替えます。最初の「ページを触る」では案内カードを表示せず、先生の説明で進めます。2〜5の「試してみよう」には、操作・変更例・移動先をまとめたカードが2〜3枚並びます。この5場面に順番の強制やクリア判定はありません。別に、約15分で取り組める「チャレンジ」を用意しています。

1. **ページを触る**：キャラと特技を選び、動きやリンクを試す。「どこを変えてみたい？」からコードへ。
2. **文字を変える**：プロフィールの名前や紹介文を一緒に書き換える。「名前を書き換える」はタグの内側の文字を選ぶので、そのまま入力できます。
3. **見た目を変える**：キャラの大きさや色合いを変える。「ほかも試す」→「背景色のコードへ」で背景の色コードを選び、パレットからコピーした色を自分で貼り付ける。「フォントを変える」では書体と使う場所を選び、コピーしたCSSを末尾へ貼り付ける。
4. **画像とリンク**：画像を入れ替えてsrcを見る。別ページへ移ってhrefを見る。
5. **自分のページ**：自由に作り替え、変えたところとそのコードを一つ見せ合う。

切り替えるのは表示する欄だけです。作品・画像・現在のページ・履歴は変わりません。「名前を書き換える」「リンクの行き先を見る」のような明示的な操作だけが対象ページへ移動します。

「試してみよう」のカードは、コードの場所や操作画面を開く入口です。例の数値を自動で書き換えることはありません。2〜5の「ほかも試す」には追加の移動先を2つずつ用意しています。先に進める生徒が別の箇所を試す入口として使えます。

先生用PDFに50分の進行例を収録しています。教材の画面には先生用の説明を表示しません。タグツアーは必要なタグだけ確かめる補助として使います。

## 読みやすさと編集画面

本文・主要ボタン・コードは18pxを基本とし、補足16px、技術的な表示は14px以上にしています。通常の文字色は濃紺、教材画面の背景はごく薄い青です。

PC向けには画面の高さに合わせた構成にし、案内・編集・表示・履歴を一つの画面内に配置しています。コード欄は内部をスクロールします。生徒の編集で作品が大きくなった場合などはプレビュー内をスクロールできます。画面サイズやブラウザ拡大率による実際の収まりは学校端末で確認してください。


- **プロフィール / もっと見る**：`index.html` と `about.html` のHTML全文を切り替えます。`style.css` は2ページで共通です。
- **コードの色分け**：タグは赤みのある色、属性名は黄色、文字列は緑、リンク先は青緑。CSSのセレクタはピンク、プロパティは水色、数値・色コードは紫に分けています。CodePenに近い役割ごとの色分けを使い、教材の暗い背景で読みやすい明るさに調整しています。
- **範囲選択**：文字をドラッグで選んだままコード欄の上端・下端へ動かすと、スクロールしながら選択範囲を広げられます。
- **ライブ表示**：入力から約220ms後に反映します。日本語の変換中は確定を待ちます。境界のドラッグや矢印キーで表示幅を変えられます。
- **コードの場所**：マウスを重ねると要素を点線で囲み、コードへ移る操作を表示します。Macは⌘ Command、WindowsはCtrlを押しながらクリックすると、HTMLの対応箇所を表示して強調します。このときリンク移動や特技は実行しません。重ねただけではコードを動かしません。普通のクリックではリンクや特技が動きます。場面ごとの「名前を書き換える」などのカードからも移れます。プレビューでShiftだけを押してもCSSへは移りません。
- **HTMLとCSSを行き来する**：コード欄でShiftを押しながらクリックすると、HTMLから対応するCSSへ、CSSから対象のHTMLへ移れます。候補が複数あるときは一覧から選びます。コードの書き換えや履歴への追加はしません。プレビュー内のコード確認はCommand／Ctrl＋クリックのままです。
- **コードの説明**：コード欄の文字にポインターを重ね、Macでは⌘ Command、WindowsではCtrlを押すと、そのコードの意味と変えたときの違いを表示します。クリックは不要です。キーを離すと説明が消えます。HTML・CSS・JavaScriptで使え、コードの書き換えや選択範囲の変更はしません。JavaScript欄は読み取り専用のままです。
- **色を選ぶ**：CSS欄の「色を選ぶ」でパレットを開きます。虹色のバーで色合い、大きな四角で鮮やかさと明るさを選べます。HEXの欄には直接入力もでき、RGB・HSV・HSLの値も表示します。「コピー」でコピーした値をCSSへ貼り付けます。背景を変えるなら「ほかも試す」→「背景色のコードへ」で先に場所を選びます。色を選ぶだけでは作品は変わりません。
- **フォントを変える**：書体の見本を比べ、「名前・大きな見出し」「紹介文」「特技のボタン」「ページの基本フォント」から使う場所を選びます。CSSをコピーすると編集欄の末尾へ戻るので、そこへ貼り付けます。見本の文章も変えられます。フォントを選ぶだけでは作品は変わりません。
- **1つ前に戻す / 1つ先へ進む / 最初から**：画面下に常設。最大40段階です。「最初から」でキャラ選択へ戻れます。「このページ」は現在のキャラと選択特技を保ち、現在ページのHTMLだけを初期状態に戻します。ページのリセットと新しいキャラでの開始も取り消せます。⌘Z、⇧⌘Zに対応します。プレビューのページ移動履歴は別です。
- **テーマ**：図鑑・ネオン・ポスター。HTMLは保持し、CSS全体を入れ替えます。変更したCSSの場所も開いて示します。自作CSSも置き換わりますが履歴から戻せます。
- **CSSあり / CSSなし**：作品のCSS、styleタグ、style属性を外します。CSSを外した際の注釈は画面に重ねません。

`<link rel="stylesheet" href="style.css">` を消すとCSS欄の内容は使われません。HTMLはhead・bodyを含む文書全体です。

## HTMLとCSSを行き来する

HTMLのタグやclass、idなどをShift＋クリックすると、その要素に対応するCSSを探します。CSSのセレクタやその中の指定をShift＋クリックすると、今のページで対象となるHTMLを探します。移動先が複数ある場合は候補を表示し、選んだ箇所を開きます。今のページに対応先がない場合は移動しません。親要素から引き継いだ指定まで探す機能ではありません。

たとえば `class="character"` と `.character { ... }` を往復し、内容と見た目のつながりを確かめます。通常のクリックやドラッグは編集・文字選択に使えます。JavaScript欄はこの移動の対象ではありません。

## コードに説明を出す

「コードを見る」を開き、気になる文字にポインターを重ねてCommandを押します。タグ名だけでなく、属性、CSSのセレクタ・プロパティ・値、JavaScriptの構文にも説明を用意しています。画面上の要素をCommand＋クリックしてコードへ移り、そこでCommandを押して意味を確かめる使い方もできます。

たとえば `class="character"` は要素をCSSやJavaScriptから見つけるための名前、`.character` はそのクラスを持つ要素を選ぶ指定として説明します。`width: 220px` なら幅、`hue-rotate(0deg)` なら画像全体の色合いを回す角度を扱います。`data-head` などは、用意したJavaScriptが読み取る独自の指定であることを区別します。

説明は教材内に収録してあり、外部への問い合わせはありません。初期ページ・テーマ・キャラ編集・動作コードで使う指定を中心に説明し、追加されたコードにも種類に応じた基本説明を出します。未知の名前や組み合わせを含む任意のコードの動作まで判断する機能ではありません。実際の変化はプレビューと見比べます。

## フォントをコピーして使う

「フォントを変える」には24書体（日本語16・英字8）を収録しています。丸い文字、手書き、明朝、ドット文字などを見本で比べられます。英数字向けの書体では日本語は別の書体で表示します。

使う場所は「名前・大きな見出し」なら `h1`、「紹介文」なら `.bio`、「特技のボタン」なら `.skills button`、「ページの基本フォント」なら `body` です。基本フォントは子の要素にも引き継がれますが、別の `font-family` が個別に指定されている部分には反映しません。書体と場所を選んで「CSSをコピー」を押し、編集欄の末尾に貼り付けます。貼り付けた `font-family` が書体の指定です。選択からコピーまででは作品のコードを書き換えません。

フォントのデータは教材に同梱しているため、ダウンロードした教材でも通信せずに使えます。保存した作品HTMLとCodePenへの出力には、作品で使っている収録フォントだけを含めます。通常のHTML・CSSのコピーだけを別のサイトへ貼る場合は、フォントのデータも必要です。フォントごとの出典は `fonts/manifest.json`、ライセンス全文は `fonts/LICENSES.txt` に収録しています。

## キャラの見た目を変える

HTMLの `img` の `src` で画像を指定します。初期素材は5体です。自分の画像へ入れ替えることもできます。

CSSの `.character` には幅・色合い・向きの指定を用意しています。「見た目を変える」の「大きさを変える」「色合いを変える」「向きを変える」で編集する数値へ移れます。カードに出る数値は試すための例です。

```css
.character {
  width: 220px;
  filter: hue-rotate(0deg);
  transform: scaleX(1);
}
```

- `220` を `120` へ：幅を小さくする。
- `0` を `120` へ：色合いを変える。
- `1` を `-1` へ：左右を反転する。

キャラ編集で体やアクセントの色を選ぶと、CSSへ `--body-color` や `--accent-color` が追加されます。その後はパレットからコピーした色コードをこの値へ貼り付け、直接編集できます。`hue-rotate` は画像全体の色合いを回す角度なので、ここには色コードではなく数値を入れます。

### キャラ編集からコードを見る

Macでは初期キャラをOption＋クリック、WindowsではAlt＋クリックすると、右側にキャラ編集が開きます。「テーマ・画像・キャラ」→「キャラを編集する」からも開けます。開くだけでは作品は変わりません。

色・頭・手・足・装備を選ぶと見た目が変わり、対応するコードも表示します。色はCSSの `--body-color` / `--accent-color`、パーツはHTMLの `img` にある `data-head` / `data-hands` / `data-feet` / `data-gear` へ反映します。`data-character` は元のキャラを記録する属性です。パーツはHTMLの標準機能で描かれるのではなく、用意したJavaScriptが指定を読み取って描きます。

変更は紹介ページと「もっと見る」のキャラに反映し、「1つ前に戻す」で取り消せます。自分で取り込んだ画像をパーツ編集用のキャラへ勝手に置き換えることはありません。元のキャラへ戻す操作を選んでからパーツを編集します。Command／CtrlとOption／Altを同時に押した場合はコードへの移動を優先します。

HTMLは内容、CSSは見た目、JavaScriptは動きとして画面と対応させます。「JavaScript」を押すと用意済みの動作コードを見られます。ここでは読み取り専用です。

## 自分の画像

「画像を追加・選ぶ」で、取り込む→使う場所を選ぶ→「この画像を使う」の順に進みます。画像を取り込んだだけではHTMLは変わりません。

PNG・JPEG・WebPに対応。1枚8MBまで、追加8枚までです。画像は長辺768px以下へ縮小してブラウザ内に保存します。処理後の画像データの総量にも上限があります。読み込み前に縦横8192px・3200万画素以下か確認します。

標準ではプロフィールと「もっと見る」のキャラを一緒に変更します。現在ページの別のimgを選ぶことや新しいimgの追加もできます。`src="uploads/img-…webp"` という短いパスとaltだけを書き換えます。画像名と説明を編集でき、使っていない画像は削除できます。使用中は削除できません。

画像は自動保存・編集JSON・作品HTMLに含まれます。CodePenへ送る場合も画像データを含みます。

## リンクとキャラの動き

プロフィールの `<a href="about.html">` で別ページへ移ります。教材内では別のHTML全文を読み込む方式です。`href="#skills"` は同じページ内へ移動します。HTTPS/HTTPリンクは別タブで開きます。

5体それぞれに固有技を6個、合わせて30個用意しています。開始時に1〜3個を選び、編集を始めてからも入れ替えられます。

画像の下には、今使っている特技と6個の候補を表示します。候補の特技をクリックしてから入れ替え先の枠をクリックすると、その枠の特技が変わります。候補を枠へドラッグしても入れ替えられます。すでに使っている特技同士をドラッグすると、並び順を変えられます。

候補を選んでいないときは、今使っている特技を押すとキャラが動きます。編集用の「特技を入れ替える」からも操作できます。

選んだ特技はプロフィールのボタンの `data-skill` に書かれます。入れ替えや並べ替えをすると、変わったHTMLを表示します。ボタンの文字と、JavaScriptが読む特技の名前を見比べられます。1回の入れ替えは「1つ前に戻す」で取り消せます。

プロフィールの特技を押すと、キャラが跳ぶ・走る・シールドを出すなどの動きをその場で見られます。ゲームの開始、移動キー、ステージ、クリア条件はありません。「もっと見る」のページでは、見出し・文章・リスト・画像を使って好きなものを紹介します。

**生徒が編集するのはHTMLとCSSです。JavaScript欄はキャラの動きに使う実際のコードを表示する読み取り専用の欄です。** `character-actions.js` を読むscriptタグを消すと、そのページでは特技が動きません。生徒が追加したscriptやイベント属性などは実行しません。

## チャレンジ

「チャレンジ」を開くと、完成見本と同じ紹介カードを作る練習に入ります。元の作品とは別のコードで進め、途中の状態も別に自動保存します。「作品に戻る」で元の編集に戻れます。

最初の3問は選択式です。名前の見出しに `h1`、説明文に `p`、カードの背景と枠にCSSを選びます。正解したパーツがページに加わり、次へ進めます。間違えてもその場で選び直せます。

「仕上げに進む」の後は、できたコードの6か所を自分で編集します。「やること」を押すとヒントが開きます。コードの場所へ移動したり、書き換える文字を自動で選択したりはしません。生徒がHTMLとCSSを読み、編集する箇所を探します。

| 編集する場所 | 指定する内容 |
|---|---|
| HTMLの `h1` の文字 | ソラ |
| HTMLの `p` の文字 | 好きなことはゲームと音楽。 |
| CSSの `body` の `background-color` | `#dbeafe` |
| CSSの `h1` の `color` | `#1d4ed8` |
| CSSの `img` の `width` | `16px` を `64px` へ |
| CSSの `.card` の `border` | `12px outset #334155` |

画像の幅は初めに小さくなっています。`width: 64px;` に直すと大きくなり、`height: auto;` で縦横比を保ちます。枠は `border: 12px outset #334155;` に変更します。3つの値は、枠の太さ・種類・色です。

見本と自分のページを比べ、「できたか確かめる」で判定します。6項目とページの構造が合うと「COMPLETE!」の演出が出ます。パーツ選び4分、編集8分、確認3分の計15分が目安です。生徒用PDFの3ページ、先生用PDFの4ページに問題・指示・解答を収録しています。

上部の「戻す」は直前の操作を取り消し、「やり直す」は取り消した操作を再実行します。「リセット」は確認を出してチャレンジだけを最初に戻します。リセット自体も「戻す」で取り消せます。元の作品の履歴とは別です。

チャレンジは左側に見本と課題を置き、右側を自分のページとコードの作業枠にしています。HTMLとCSSの両方が右側のページに反映されます。見本は作業枠の外に分け、2つのページは同じ表示幅で比べられます。画面の外側には余白を取り、課題を選んでもエディターの位置や選択範囲は変えません。

## タグツアー

自分の作品を保持したまま見本を使います。ツアーのコードは読み取り専用です。開くとHTML/CSSの両方を表示し、閉じると元の表示に戻ります。

1. h1：名前を変える。
2. p：文章を2つの段落に分ける。
3. img：srcとaltを変える。
4. a：「もっと見る」のHTMLへ移動する。
5. ul / li：リスト項目を増やす。
6. div：まとめた範囲を示してCSSで色を変える。
7. class / CSS：キャラの幅を220pxから120pxへ変える。

h1は文字サイズそのもの、divは枠そのもの、classはタグの種類として説明しません。buttonとJavaScriptの関係はタグ一覧・先生用ガイドでも説明しています。

## 保存と再開

- **作品をHTMLで保存**：2ページ・画像・CSS・キャラの動きを1ファイルにまとめます。保存後もページ移動と特技が動きます。URLのハッシュとブラウザの戻る操作に対応します。
- **編集データを保存**：2ページのソース、画像、テーマをJSONに保存。この教材で読み込んで再開できます。
- **CodePenで開く**：HTML欄はプロフィール、CSS欄は共通CSSです。リンク先ページとキャラの動きはJS欄に渡します。CodePenでプロフィールのHTMLやCSSを編集できます。両ページのHTMLを別々に編集するならこの教材を使います。追加のinline styleはCodePenで共通CSSの後に適用されるため、元のHTMLの順番と異なる場合があります。
- **コピー**：現在ページのHTML全文と共通CSSを個別にコピーできます。コピーだけの場合は特技の動作コードを含みません。

ツアー中も自分の作品を保存します。CSSなしの表示中でも作品にはCSSを付けます。自動保存できない場合は画面上に表示します。編集履歴は再読み込み後には残りません。

生徒版は従来のゲーム付き教材とは別に保存します。授業で配布するときは生徒版のURLまたはZIPを使います。

- `syntax.js` / `syntax.css`：コードの役割ごとの色分け。
- `editor-selection.js`：範囲選択中のスクロール。
- `skill-editor.js` / `skill-editor.css`：特技の入れ替えとHTMLへの反映。
- `challenge-model.js` / `challenge.js` / `challenge.css`：選択問題、編集課題の判定、見本と操作画面。
- `app.js`：編集・履歴・画面操作・保存。
- `preview.js`：プレビュー、リンク処理、作品HTML/CodePen出力。
- `images.js`：画像管理。
- `character-actions.js`：プロフィールで見せるキャラの動き。
- `runtime-source.js`：キャラの描画と動作をプレビュー・保存作品へ渡す生成ファイル。
- `lesson.js`：5場面、キャラの見た目を編集する入口、コード欄の表示切り替え。
- `code-references.js` / `code-navigation.js` / `code-navigation.css`：HTMLとCSSの参照先を探し、Shift＋クリックで移動。
- `code-help.js` / `code-help.css`：コード上の位置を調べ、修飾キーを押している間だけ説明を表示。
- `code-explain-html.js` / `code-explain-css.js` / `code-explain-js.js`：言語ごとのコードの読み取りと説明。
- `palette.js` / `palette.css`：色の選択と色コードのコピー。
- `font-data*.js` / `font-library.js`：収録フォントのデータと読み込み・出力。
- `font-picker.js` / `font-picker.css`：書体の見本、使う場所の選択、CSSのコピー。
- `character-studio.js` / `character-studio.css`：キャラ編集の操作画面。
- `character-renderer.js`：HTMLのパーツ指定とCSSの色指定をキャラの表示へ反映。
- `app.css` / `v3.css` / `classroom.css` / `viewport.css`：教材画面と読みやすさ、画面高に合わせた配置。
- `assets-v2.js`：オリジナル5キャラのSVGデータ。

キャラの動作を変更したら `python3 tools/build/runtime.py` で生成ファイルを更新してください。

`tools/qa` にコアデータ、画像、プレビュー、実アプリ接続などの検証があります。DOM検証にはlinkedomが必要です。`PIXEL_QA_LINKEDOM` にインストール先を指定できます。これは開発用で配布教材には不要です。

生徒版の検証結果は `.lecture/review.md` に記録します。PDFは生徒用3ページと先生用4ページを画像にして確認しました。

授業で使う前に学校端末で、範囲選択時のスクロール、特技のドラッグ、チャレンジ、色とフォントのコピー・貼り付け、Shift＋クリックでの移動、コードの説明表示、画像追加、特技の動き、保存したHTML、CodePenを確認してください。コードとDOMの検証だけでは、実ブラウザの描画や端末入力までは確認できません。
