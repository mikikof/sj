使い方
画面からコードへ
文字や画像にポインターを重ねると点線で囲まれます。⌘ Commandを押しながらクリックすると、その部分のHTMLへ移ります。WindowsはCtrlです。
キャラを⌥ Option＋クリックするとキャラ編集が開きます。WindowsはAltです。リンクや特技は普通のクリックで動きます。「コードを見る／コードを隠す」でコードを開閉できます。
コードの意味を調べる
コードにポインターを重ねて⌘ Commandを押すと、その部分の意味と、変えたときの変化が出ます。WindowsはCtrlです。キーを離すと閉じます。HTML・CSS・JavaScriptのどの欄でも使えます。
HTMLとCSSを行き来する
コードの上でShiftを押しながらクリックすると、対応するHTMLやCSSへ移ります。候補が複数あるときは一覧から選びます。コードは書き換わりません。表示結果からHTMLへ移る操作は⌘ Command＋クリックです。
キャラと特技
キャラごとに6つの特技があります。画像の下で技を選び、入れ替える場所を押します。候補から使う枠へドラッグしても交換できます。入れ替えると、変わったHTMLが表示されます。使っている特技を押すと、その場でキャラが動きます。
キャラの見た目
「見た目を変える」から色・大きさ・向きのコードへ移れます。数字を変えるとすぐに反映されます。
「色を選ぶ」では虹色のバーで色合いを選び、色の面で明るさや鮮やかさを調整できます。色コードをコピーしてCSSに貼り付けます。「フォントを変える」では文字の見本と変更する場所を選び、CSSをコピーします。移動したCSSの一番下に貼り付けると字体が変わります。各場面の「ほかも試す」から別の場所も試せます。
キャラ編集では色・頭・手・足・装備を変えられます。色はCSS、パーツはHTMLの指定に反映します。テーマを選ぶとCSS全体が入れ替わり、変わったコードが表示されます。
チャレンジ
3つの問題でパーツを選び、見本と同じカードを作ります。その後は名前・説明文・色・画像の大きさ・枠線を書き換えます。課題を押すとヒントが出ます。コードの場所は自分で探してみましょう。「できたか確かめる」で仕上がりを確認できます。「戻す」「やり直す」で編集を取り消したり戻したりできます。「リセット」はチャレンジだけを最初の状態に戻します。途中で閉じても続きから再開できます。
戻す・保存する
「1つ前に戻す」で編集を戻せます。⌘Z、⇧⌘Zでも戻す・進むが使えます。
「最初から」でキャラ選択へ戻ります。「続きから」で今の作品を開けます。新しいキャラで始めた後も「1つ前に戻す」で戻せます。
「保存」から作品をHTMLで保存できます。後で編集を再開するなら編集データを保存してください。
特技の動きはJavaScriptで用意しています。「JavaScript」で実際のコードを読めます。編集するのはHTMLとCSSです。


HTML / CSS
タグとCSSの読み方
HTMLのタグは内容の役割を表します。見た目はCSSで指定できます。
<h1>ミント</h1>
タグ意味
htmlHTML文書全体を囲む。
headページの設定などを書く。本文とは別の部分。
titleタブなどに表示するページ名。
body画面に表示する内容を書く。
h1 / h2見出し。h1が最も上のレベルでh2はその下のレベル。
p文章の段落。
img画像。srcで場所を指定しaltに代わりの説明を書く。終了タグはない。
aリンク。hrefで移動先を指定する。
button操作するためのボタン。この教材の特技は用意されたJavaScriptで動く。
ul / li順序を表さないリストとその項目。
div要素をまとめる。div自体には特別な意味はない。
span文章などの一部分をまとめる。
CSSは「どこを・何を・どう変えるか」
.character {
  width: 220px;
}
.characterはclass="character"の要素を選びます。widthは幅、220pxはその値です。
classはタグの種類ではなく要素につける名前です。CSSの.はclassを選ぶときの記号です。
